1. Introducción a CSS

CSS significa Cascade Style Sheets (Hojas de Estilo en Cascada).

CSS es un lenguaje utilizado para diseñar y dar apariencia a las páginas web creadas con HTML.

Con CSS podemos cambiar colores, tamaños, fuentes, márgenes, bordes, posiciones y distribución de los elementos.

2. Identificadores

Un identificador o ID permite darle un nombre único a un elemento HTML.

En este ejeemplo, el título principal tiene: id="titulo"

Este texto utiliza una clase CSS llamada "importante"

3. Selectores

Los selectores en CSS nos permiten seleccionar elementos HTML para aplicarles estilos.

4. Cajas

En CSS, todos los elementos se consideran cajas rectangulares.

5. Maquetación

La maquetación en CSS se refiere a la disposición y organización de los elementos en una página web.
